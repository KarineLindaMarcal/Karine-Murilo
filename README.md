# 💍 Site de Casamento – Karine & Amor

Este projeto é um **site de casamento elegante**, inspirado no design marsala e dourado do convite oficial.  
Inclui **contagem regressiva**, **convite digital**, **formulário de confirmação de presença (RSVP)** e layout romântico.

---

## 🌹 Funcionalidades

- 🎨 Tema marsala + dourado inspirado em convite de casamento  
- ⏳ Contagem regressiva até **22/11/2026 às 08:30**  
- 💌 Convite digital estilizado  
- 📝 Formulário para confirmação de presença  
- 📱 Layout responsivo  
- ✨ Efeitos suaves e elementos visuais com brilho
